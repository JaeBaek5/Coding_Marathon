# Design System & Migration Guide
This document details the visual design contract for Mumuk.

## Preset
- Source of truth preset: `b7CSd9JdZ`
- Technology: `shadcn-svelte`

## Design Tokens & Component Styles
- **Button**: `.button-primary` (uses primary theme colors)
- **Card**: `.card` (uses card background tokens)
- **Input**: `.text-input` (uses input border and ring tokens)
- **Select**: `.pill-select` (uses active primary indicator)

## No behavior changes
No behavior changes are introduced in this styling migration. The core application logic remains decoupled from presentation tokens.
